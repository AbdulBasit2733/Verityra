# Skill routing

Select skills by the work being performed; do not run every installed skill for every task.

| Task | Required routing |
| --- | --- |
| New feature or architecture | `using-superpowers`, `brainstorming`, `writing-plans`, GStack planning/review skills as appropriate |
| UI, responsiveness, accessibility | `ui-ux-pro-max`, `design-system`, `ui-styling`, then design review |
| Bug diagnosis | `systematic-debugging`, `diagnosing-bugs`, GStack `investigate` |
| Implementation | `test-driven-development` or `tdd`, `codebase-design` for seams and module boundaries |
| Small, low-risk cleanup | `ponytail` after confirming the smallest safe change is sufficient |
| Verification and handoff | `verification-before-completion`, GStack `qa`/`review`, and `writing-for-agents` when handing off |

Agents must read each selected skill's `SKILL.md` before acting and must document any non-trivial work under `docs/`.
