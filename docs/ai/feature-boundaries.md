# Feature boundaries and invariants

- Candidate UI never receives rubrics, model prompts, moderator notes, or private evaluator instructions.
- Server authorization remains authoritative; component placement does not authorize access.
- A test registration has a maximum of three attempts. Compensation is limited to terminal system failures.
- Refund behavior preserves the seven-day policy, attempt-forfeiture acknowledgement, payment reconciliation, and immutable audit history.
- Upload safety, validation, payment behavior, evaluation behavior, and persistence contracts are unchanged unless explicitly approved.
- Keep public marketing free of confidential evaluation instructions and unsupported automated-grading claims.
